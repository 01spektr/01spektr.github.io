# Калькулятор кровли: состояние локальной версии

Дата: 2026-09-08. Публикация в GitHub не выполнялась.

Адрес разработки: http://localhost:8080/tools/roof-calculator

Реализованы четыре математические модели: двускатная, вальмовая с одинаковыми углами и свесами, односкатная, симметричная мансардная с двумя углами и горизонтальным положением излома.
Свесы горизонтальные. Высота H измеряется от верха стен. Несущая способность не рассчитывается.
Схема SVG параметрическая, отдельного 3D-движка нет. Доступны аксонометрия и разрез.
Материалы: покрытие полосами по рабочей ширине, продольный нахлёст, целые листы, дополнительный запас; конёк и вальмовые планки, саморезы. Обрезки между скатами не переиспользуются, поэтому вальмовая оценка консервативная.
Смета вводится пользователем в UZS. Не включены работы, доставка, несущие конструкции, водосток, планки излома мансардной крыши и остальные доборные элементы.
Сохранение полных расчётов с избранным и удалением — localStorage toolboxi-roof-projects-v1. Параметры также передаются через URL и глобальную историю.

Проверки: TypeScript, 11 тестов ядра, сборка GITHUB_PAGES=true, прямое открытие статической страницы и интерактивность, мобильный экран 390 px без горизонтального переполнения; ошибок браузера в проверенных сценариях нет.
Дополнительный модуль калькулятора: около 11,14 КБ JS + 4,22 КБ CSS gzip. Общие зависимости сайта в эти цифры не входят; сборка предупреждает о другом крупном общем чанке.

Исходные файлы калькулятора и app-shell перед изменением сохранены в .review-backups/roof-before-implementation.
Ранее существовавшие изменения sidebar, UUID, image-resize и каталога оставлены на месте.
Следующий этап: пользовательская оценка композиции и желаемой детализации схемы, затем отдельная проверка расхода конкретных профилей поставщиков до использования для заказа.
