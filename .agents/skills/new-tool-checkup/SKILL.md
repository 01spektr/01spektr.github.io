# Регламент добавления нового инструмента на Toolboxi.uz (Чекап)

Этот документ — жесткий чеклист, по которому ВСЕГДА проверяется и интегрируется любой новый инструмент на сайт Toolboxi.uz.

---

## 1. СТРОГИЙ ПОРЯДОК РАБОТЫ (WORKFLOW)
1. **Только локальная разработка сначала:** Все изменения вносятся и тестируются на локальном dev-сервере (`npm run dev` на `http://localhost:8080/`).
2. **Демонстрация пользователю:** После сборки отправляется ссылка на локальный сайт, перечисляются выполненные пункты.
3. **Запрет на самостоятельную публикацию:** `git push` и `git commit` выполняются **ТОЛЬКО** после явной команды пользователя («публикуй»).

---

## 2. ЧЕКАП ПО ДИЗАЙНУ И UI (BENCHMARK)
Ориентир — `loan-calculator` и `customs-calculator`.

1. **Контейнер страницы:**
   - Строго `max-w-[1380px] w-full mx-auto px-4 sm:px-6 lg:px-8 py-3 sm:py-6`.
2. **Шапка инструмента (`HeroBanner`):**
   - **Хлебные крошки:** Главная → Категория → Название инструмента.
   - **Действия:** Сохранённые/История (если есть), Избранное (`toggleFavorite`), Поделиться (`shareUrl`).
   - **Главный заголовок (`<h1>`):**
     - **ВАЖНО:** Заголовок должен быть лаконичным, в **ОДИН РЯД** (использовать `sm:whitespace-nowrap`).
     - Не раздувать заголовок словом «Калькулятор...», если оно длинное (например: «Расход топлива грузовика»).
     - Слово «онлайн-калькулятор» гармонично переносить в подзаголовок.
     - Никаких лишних надстрочных бейджей над заголовком, которые раздувают высоту шапки.
   - **Компактная высота:** Внутренние отступы `p-4 sm:p-5`, иконка стандартная `w-12 h-12` с градиентом.
   - **Бейджи преимуществ:** 3 аккуратных мини-бейджа справа.
3. **Живые метрики (`MetricsCards`):**
   - Статус-бар сверху с кнопками «Скопировать итог» и «Сбросить».
   - 3 карточки ключевых числовых результатов с чистыми контрастными иконками.
4. **Сетка рабочего пространства (2 колонки):**
   - Левая колонка (8 колонок на десктопе): Форма ввода с шагами.
   - Правая колонка (4 колонки на десктопе, `sticky top-20`): Результаты расчёта, детализация, экспорт в PDF.
5. **Сворачивание второстепенных параметров:**
   - **ПРАВИЛО:** Дополнительные/необязательные условия (погода, сезон, расширенные коэффициенты) **ВСЕГДА свёрнуты по умолчанию** (`useState(false)`). Пользователь раскрывает их только при необходимости.
6. **Нижний блок (`BottomCards` / Справочные материалы):**
   - 3 независимые раскрывающиеся карточки:
     1. Формулы и нормативы / Руководство;
     2. Частые вопросы (FAQ) — независимый плавный аккордеон с понятными ответами;
     3. Практические советы / Рекомендации экспертов.
   - Баннер обратной связи («Помогите сделать инструмент лучше»).
7. **Темы Light / Dark:**
   - Никаких `@import "tailwindcss"` внутри css фич.
   - Никаких принудительных `.dark ... !important` цветов, ломающих светлую тему.
   - Все поля ввода, выпадающие списки и карточки должны иметь идеальный контраст в обеих темах.

## 3. ЧЕКАП ПО SEO И МУЛЬТИЯЗЫЧНОСТИ (I18N)
1. **Все 3 языка обязательны:**
   - Русский (`ru`), Узбекский (`uz`), Английский (`en`).
2. **Создание маршрутов (`src/routes/`):**
   - `ru_.tools.<slug>.tsx`
   - `uz_.tools.<slug>.tsx`
   - Добавление ветки в `src/routes/tools/$slug.tsx` (дефолтная/английская версия).
3. **Регистрация в `src/lib/i18n/config.ts`:**
   - Обязательно добавить `<slug>` в `LOCALIZED_TOOL_SLUGS`. Без этого переключатель RU / UZ / EN в шапке сайта сломается и будет выкидывать на главную!
4. **Файл `seo.ts` в папке фичи (`src/features/<slug>/seo.ts`):**
   - Уникальные `title` и `description` для RU, UZ, EN с ключевыми поисковыми фразами.
   - `alternates` с `hreflang`: `"en"`, `"ru"`, `"uz"`, `"x-default"`.
5. **Каталог `src/lib/tools/catalog.ts`:**
   - Назначить правильную категорию (`logistics`, `finance`, `business`, `construction`, etc.).
   - Локализованные названия и описания на трёх языках.
   - Релевантные поисковые `keywords` (русские, узбекские, английские, транслит).
   - Иконка из Lucide.
